# Timer Project

## About The Project

This is a simple desktop application made with **C#** and **Windows Forms**.

The application has three tools:

* **Current Time:** Shows the current time.
* **Stopwatch:** Counts the time up and allows you to start, stop, and reset it.
* **Timer:** Counts down from a set amount of time.

## Technologies Used

* **Language:** C#
* **Framework:** .NET Framework 4.7.2
* **UI:** Windows Forms
* **IDE:** Visual Studio

## How It Works

* The main form gives access to the different tools.
* Each tool has its own form.
* The **Stopwatch** counts the elapsed time.
* The **Current Time** updates every second.
* The **Timer** counts down until it reaches zero.
* Some images used in the application are stored in the `Resources` folder.

## How to Run

1. Open the project in **Visual Studio**.
2. Open the `Timer Project.slnx` or `Timer Project.csproj` file.
3. Press **Start** or **F5**.
4. The application will start.
